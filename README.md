Trash is Eternal is a 2D side scrolling trash management game
It touches on the 11th Sustainable Development Goal: sustainable community and cities
It aims to be a medium for reflection regarding littering, considering the players will be playing as a roomba named C4k3 to clean the trash being constantly dropped by the npcs in the game.

Important Features include: The littering mechanics itself which has rates that can be multiplied later via random event; environmental storytelling which can be seen by the sprite and image assets; upgrade system where upgrading gives access to better support turrets that can further help with managing the trash but also has a downside of ramping up game difficulty to encourage decision making from the players.
OOP implementation include: Abstraction via the use of Scenes to display the game running and hiding the logic behind scripts; Inheritance via having like subclasses Organic Plastic and Metal inheret from Trash and its methods; Polymorphism via having the three trash subclasses use the same attribute names but differ in values; Encapsulation via having the variable score privated and using setters to change its value and using getter to display the saved highest.

Setup instructions:
(1) Open the Trash Eternal/Builds folder; (2) Download and extract the Trash Eternal zip file into a folder; (3) Open the folder and click on Trash Eternal.exe; (4) Enjoy!
